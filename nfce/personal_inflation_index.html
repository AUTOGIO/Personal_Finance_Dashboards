Metodologia

A regra continua simples e local.

Cada produto é identificado pelo código de barras (EAN) ou, na falta dele, pela descrição normalizada dentro da mesma rede (CNPJ), sempre separado por unidade de venda (UN, KG…). O preço mensal é a mediana do preço unitário no mês. Entre compras consecutivas do mesmo produto, a variação de preço (em log) é distribuída pelos meses do intervalo; variações acima de 4× são descartadas como troca de produto ou erro de cadastro. A inflação de cada mês é a média dessas variações ponderada pelo gasto do produto, e o índice é o encadeamento mensal com base 100 no primeiro mês. Para regenerar: python3 personal_inflation.py.
